# IV_jump-detector-for-options-pricing

Locating Implied Volatility Jumps to Identify Anomalies in Strike Prices

Kenneth A. Anderson,  Ph.D.

This project introduces an implied volatility (IV) Jump Detection technique by leveraging the discrete analog of distributional derivatives. The goal was to assess changes in IV relative to strike prices. The Jump Detector is able to identify unexpected jumps in IV, which may prompt further investigation for mispriced/misordered strike prices. Using second-order finite-differences of IV between neighboring strike prices, a six-step procedure was employed to demonstrate the utility of the Jump Detection Technique with real stock data.

This project was completed in partial fulfillment of a quantitative finance professional development course offered through The Erdos Institute (erdosinstitute.org). Each participant was required to complete a final project that explored financial concepts in a creative way.
